# よくある質問

このドキュメントでは、api.Kipfel.link 動画パースサービスを使用する際のよくある質問をリストします。

## サポートされているコンテンツ

::: info サポートされているプラットフォーム
- **動画プラットフォーム**: 抖音、Bilibili、YouTube、Twitter(X)、Instagram、快手、AcFun
- **ライブサポート**: Bilibiliライブ、抖音ライブ、快手ライブ（自動的な短縮リンク検出をサポート）
- **音楽プラットフォーム**: 网易云音乐、酷狗音乐、咪咕音乐、YouTube Music
- **パースタイプ**: 単一動画、コレクション（Bilibiliマルチパート/YouTubeプレイリスト）、単一音楽、音楽プレイリスト
:::

## ライブパースに関するメモ

::: tip ライブパース機能
- **マルチプラットフォームカバー**: Bilibili、抖音、快手の3つの主要ライブプラットフォームをサポート
- **短縮リンク互換**: モバイルから共有された短縮リンク（`b23.tv`、`v.douyin.com` など）をサポート、システムが自動的にリダイレクトとパースを実行
- **自動検出**: タイプを選択する必要はありません。ライブルームのリンクを直接貼り付けるだけで（キャプションを削除！キャプションを削除！キャプションを削除！重要なことを3回！）、システムが自動的にライブパースエンジンに切り替えます
:::

::: warning 注意
ライブリンクは通常、強い時効性と盗リンク防止制限があります。パース後は速やかに使用することをおすすめします。
:::

## 基本的な質問

::: details ウェブページでは正常に再生できるのに、VRChatでは再生できないのはなぜですか？
VRChatの内蔵プレイヤー/一部のプレイヤーは、302リダイレクトまたは長いURLのサポートが不完全です。まずコピーしたURLをブラウザで開いてパースし、最終アドレス（通常は直リンクになります）にリダイレクトさせてから、そのリダイレクト後のURLをVRChatにコピーして再生してください。
:::

::: details 一部のルームで再生できないのはなぜですか？
VRChatの2024.12.11の更新後、公式はすべてのワールドに独自の[ドメインホワイトリスト](https://docs.vrchat.com/docs/whitelists)を設定することを強制しています。その目的は、パブリックルームではワールド作者が設定したホワイトリストにあるリソースリンクのみアクセスできるように制限することです。プライベートルームは制限されていません。
:::

::: details 抖音が正常にパースできないのはなぜですか？
キャプション付きの共有テキスト、特に#記号を含むものを直接貼り付けないでください。すべてのテキストを削除してリンク自体のみを保持してから再試行することをおすすめします。
:::

::: details プレイリストのN曲目を選択するにはどうすればよいですか？なぜ再生したい曲ではないのですか？
プレイリストは1からカウントします。`&i=1` / `&i=2` を使用してN曲目を選択します。末尾に `@1` / `@2` を追加することもサポートしています。範囲を超えた場合は「プレイリストインデックスが範囲外です」と表示されます。
:::

::: details 一部の動画はパースできるのに、VRChatでカクカクしたり読み込みが遅かったりするのはなぜですか？
ソースサイトのネットワークの問題かもしれません。またはソースサイトが国内/海外アクセスを制限しているかもしれません。このサイトは動画トラフィックのプロキシを停止しているため、適切なネットワーク環境で直接ソースリソースにアクセスすることをおすすめします。
:::

::: details パブリックワールドの作者です。このパーサーのサポートを追加したいです。
[CDN リスト](/ja/video-parser/cdn)ページを確認し、ホワイトリストに追加する必要があるドメインの完全なリストを取得してください。作者に[メール](mailto:admin@kipfel.link?subject=ドメインホワイトリスト申請&body=こんにちは、[ワールド名]の作者です。このパーサーサイトのサポートを追加する必要があります。こちらがワールドの招待リンクです:)を送信し、あなたのワールドリンク情報を添付してコラボレーションしてください。コラボレーションワールドに追加されます。

::: warning 注意
VRChatワールドはURLlistを最大100エントリに制限しています。必要に応じて追加してください。
:::
:::

::: details このサイトについて特別な声明はありますか？
このサイトはKipfelコミュニティによって制作されたものではなく、Kipfelが好きな個人作者によって制作されたものです。このサイトは完全に無料です。誰かが有料で使用するよう誘導した場合は、私に報告してください。皆さんが宣伝を手伝って、より多くの人が使用できるようにしてください。ありがとうにゃー！
:::

## 一般的なエラーコード

| HTTP ステータスコード | ビジネスコード | 説明 |
| --- | --- | --- |
| `403` | 固定ビジネスコードなし | サポートされていないプラットフォームのリンクはリダイレクトが拒否されます |
| `405` | `METHOD_NOT_ALLOWED` | `url` パラメータキーがありません |
| `418` | `IM_A_TEAPOT` | `url` パラメータが空文字列です |
| `422` | `INVALID_URL` | 入力から有効な URL を抽出できませんでした |
| `422` | `MISSING_PARAMETER` | 必要なパラメータがありません |
| `422` | `UNSUPPORTED_PLATFORM` | 現在のプラットフォームまたはリンクタイプはサポートされていません |
| `451` | `CONTENT_RESTRICTED` | 著作権またはコンプライアンス上の理由でサポートされていません |
| `500` | `PARSE_ERROR` | 一般的なパース失敗 |
| `500` | `COLLECTION_PARSE_ERROR` | コレクションのパースに失敗しました |
| `500` | `PLAYLIST_ERROR` | プレイリスト詳細の取得に失敗しました |
| `503` | `NO_NODES_AVAILABLE` | 現在利用可能なパースノードがありません |
| `504` | `PARSE_ERROR` | 上流パースノードがタイムアウトまたは接続を拒否しました |
| `429` | `API_LIMIT_EXCEEDED` | API リクエストが頻繁すぎます |
