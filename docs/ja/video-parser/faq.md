# よくある質問

このページでは、api.kipfel.link のビデオ解析サービスに関するよくある質問に回答します。各質問は独立した見出しになっており、各節の最初の一文がそのまま回答です。

## 対応プラットフォームとコンテンツ

### VRChat ビデオ解析はどのプラットフォームに対応していますか？

Douyin、Bilibili、YouTube、Twitter(X)、Instagram、Kuaishou の 6 つのビデオプラットフォームに対応しています。

::: info サポートされているプラットフォーム
- **ビデオプラットフォーム**: Douyin、Bilibili、YouTube、Twitter(X)、Instagram、Kuaishou
- **弾幕サポート**: Douyin、Bilibili
- **ライブストリームサポート**: Bilibili ライブ、Douyin ライブ、Kuaishou ライブ (ショートリンクの自動認識をサポート)
- **音楽プラットフォーム**: NetEase Cloud Music、Kugou Music、Migu Music、YouTube Music
:::

## ライブ配信の解析

### ライブ配信のリンクはそのまま貼り付けるだけで解析できますか？

はい。タイプを選択する必要はなく、ライブ配信ルームのアドレスを貼り付けるだけで、システムが自動的にライブ配信解析エンジンに切り替えます。Bilibili・Douyin・Kuaishou の 3 平台に対応し、携帯から共有された短縮リンク（`b23.tv`、`v.douyin.com` など）も自動的にリダイレクトして解析します。

::: tip 貼り付ける前にコピー文を必ず削除してください
ライブ配信ルームのアドレスを貼り付ける際は、周囲のテキストをすべて削除し（コピーを削除！コピーを削除！重要なことなので 3 回言います！）、リンク本体のみを残してください。
:::

::: warning 注意
- **ライブストリーム解析**: ライブストリームリンクは通常、時間的制約が強く、盗難防止リンクの制限があります。解析後はできるだけ早く使用することをお勧めします。
- **弾幕解析**: 弾幕は現在カフェでのみ再生でき、他のマップでは使用できません。
:::

## 再生と解析の問題

### ウェブページでは正常に再生できるのに、VRChat では再生できないのはなぜですか？

VRChat 内蔵プレイヤーや一部のプレイヤーは、302 リダイレクトや長いリンクのサポートが不完全です。まずコピーしたリンクをブラウザで開いて一度解析し、最終アドレス（通常は「直リンク」）へリダイレクトさせてから、その URL を VRChat にコピーして再生してください。

### 一部の部屋で再生できないのはなぜですか？

VRChat 公式が 2024.12.11 の更新で、すべてのマップに独自の[ドメインホワイトリスト](https://docs.vrczh.org/creators.vrchat.com/worlds/udon/video-players/www-whitelist)を設定することを義務付けたためです。公開ルームでは作者がそのマップのホワイトリストに登録したリソースリンクのみアクセスでき、プライベートルームは制限されません。

### Douyin が正常に解析できないのはなぜですか？

共有テキストに含まれる `#` でブラウザ側がリンクを切り捨てるため、サーバーには `#` より後ろが届きません。コピー文付きの共有内容をそのまま貼り付けず、すべてのテキストを削除してリンク本体のみを残して再試行してください。

### プレイリストで N 番目の曲を選ぶには？ 思った曲が再生されないのはなぜですか？

プレイリストは 1 から数えます。`&i=1` / `&i=2` で N 番目の曲を選べます。末尾に `@1` / `@2` を付ける方法にも対応しています。範囲外の場合は「プレイリストのシーケンス番号が範囲外です」と表示されます。

### 解析はできるのに VRChat でカクつく・読み込みが遅いのはなぜですか？

多くの場合、ソースサイト側のネットワーク変動か、ソースサイトによる国内／海外アクセスの制限です。当サイトはビデオトラフィックの中継サービスを停止しているため、適切なネットワーク環境からソースサイトのリソースへ直接アクセスすることをお勧めします。

## マップとホワイトリスト

### 公開マップの作者です。この解析サイトのサポートを追加したいのですが？

[CDN リスト](/ja/video-parser/cdn) ページでホワイトリストに追加すべきドメインの完全なリストを確認し、作者に[メール](mailto:admin@kipfel.link?subject=ドメイン解析リスト申請&body=こんにちは、私はxxxマップの作成者xxxです。当サイトの解析サポートを追加したいです。これは私のマップの招待リンクです：) を送り、あなたとマップのリンク情報を添えてください。提携ワールドとして掲載されます。

::: warning 注意
VRChat マップの URL リストは最大 100 個しかありません。必要に応じて追加してください。
:::

## よくあるエラーコード

| HTTP ステータスコード | ビジネスコード | 説明 |
| --- | --- | --- |
| `403` | 固定ビジネスコードなし | サポートされていないプラットフォームリンクのリダイレクトが拒否されました |
| `405` | `METHOD_NOT_ALLOWED` | `url` パラメータキーがありません |
| `418` | `IM_A_TEAPOT` | `url` パラメータが空文字列です |
| `422` | `INVALID_URL` | 入力から有効な URL を抽出できませんでした |
| `422` | `MISSING_PARAMETER` | 必要なパラメータがありません |
| `422` | `UNSUPPORTED_PLATFORM` | 現在のプラットフォームまたは現在のリンクタイプはサポートされていません |
| `451` | `CONTENT_RESTRICTED` | 著作権またはコンプライアンス上の理由によりサポートされていません |
| `500` | `PARSE_ERROR` | 一般的な解析失敗 |
| `500` | `COLLECTION_PARSE_ERROR` | コレクション解析失敗 |
| `500` | `PLAYLIST_ERROR` | プレイリスト詳細の取得失敗 |
| `503` | `NO_NODES_AVAILABLE` | 現在利用可能な解析ノードがありません |
| `504` | `PARSE_ERROR` | 上流解析ノードがタイムアウトまたは接続拒否 |
| `429` | `API_LIMIT_EXCEEDED` | API リクエストが頻繁すぎます |
