# よくある質問

このドキュメントでは、api.Kipfel.link ビデオ解析サービスを使用する際のよくある質問と回答をリストしています。

## サポート内容

::: info サポートされているプラットフォーム
- **ビデオプラットフォーム**: Douyin、Bilibili、YouTube、Twitter(X)、Instagram、Kuaishou
- **弾幕サポート**: Douyin、Bilibili
- **ライブストリームサポート**: Bilibili ライブ、Douyin ライブ、Kuaishou ライブ (ショートリンクの自動認識をサポート)
- **音楽プラットフォーム**: NetEase Cloud Music、Kugou Music、Migu Music、YouTube Music
:::

## ライブストリーム解析の説明

::: tip ライブストリーム解析機能
- **マルチプラットフォーム対応**: Bilibili、Douyin、Kuaishou の主要な 3 つのライブストリームプラットフォームをサポートしています。
- **ショートリンク互換性**: 携帯電話から共有されたショートリンク (例: `b23.tv`、`v.douyin.com`) をサポートしており、システムは自動的にリダイレクトして解析します。
- **自動認識**: タイプを選択する必要はありません。ライブストリームルームのアドレスを直接貼り付けるだけで (コピーを削除してください！ コピーを削除してください！ コピーを削除してください！ 重要なことなので 3 回言います！)、システムは自動的にライブストリーム解析エンジンに切り替わります。
:::

::: warning 注意
- **ライブストリーム解析**: ライブストリームリンクは通常、時間的制約が強く、盗難防止リンクの制限があります。解析後はできるだけ早く使用することをお勧めします。
- **弾幕解析**: 弾幕は現在カフェでのみ再生でき、他のマップでは使用できません。
:::

## 基本的な質問

::: details ウェブページでは正常に再生できるのに、VRChat では再生できないのはなぜですか？
VRChat 内蔵プレイヤー/一部のプレイヤーは、302 リダイレクトまたは長いリンクのサポートが不完全です。まず、コピーしたリンクをブラウザで開いて一度解析し、最終アドレスにリダイレクトさせてください (通常は「直リンク」になります)。その後、リダイレクト後のリンクを VRChat にコピーして再生してください。
:::

::: details なぜ一部の部屋では再生できないのですか？
VRChat 公式は 2024.12.11 の更新後、すべてのマップが独自の [ドメインホワイトリスト](https://docs.vrczh.org/creators.vrchat.com/worlds/udon/video-players/www-whitelist) を設定することを義務付けました。その機能は、公開ルームでは作者が設定したこのマップのホワイトリスト内のリソースリンクのみがアクセスを許可され、プライベートタイプのルームは制限されないようにすることです。
:::

::: details Douyin が正常に解析できないのはなぜですか？
コピーを含む共有コンテンツ、特に # 記号を含むものを直接貼り付けないでください。すべてのテキストを削除し、リンク本体のみを残して再試行することをお勧めします。
:::

::: details プレイリストで N 番目の曲を選択するにはどうすればよいですか？なぜ私が望む曲が再生されないのですか？
プレイリストは 1 から数えられます。`&i=1` / `&i=2` を使用して N 番目の曲を選択します。末尾に `@1` / `@2` を追加することもサポートされています。範囲外の場合、「プレイリストのシーケンス番号が範囲外です」というメッセージが表示されます。
:::

::: details 一部のビデオは解析できますが、VRChat でカクカクしたり、読み込みが遅いのはなぜですか？
ソースサイトのネットワークの変動が原因である可能性があります。また、ソースサイトが国内/海外からのアクセスを制限している可能性もあります。当サイトはビデオトラフィックの転送サービスを停止したため、適切なネットワーク環境を使用してソースサイトのリソースに直接アクセスすることをお勧めします。
:::

::: details 私は公開マップの作成者です。この解析サイトのサポートを追加したいのですが？
[CDN リスト](/ja/video-parser/cdn) ページで、ホワイトリストに追加する必要がある完全なドメインリストを確認してください。作者に [メール](mailto:admin@kipfel.link?subject=ドメイン解析リスト申請&body=こんにちは、私はxxxマップの作成者xxxです。当サイトの解析サポートを追加したいです。これは私のマップの招待リンクです：) を送信し、あなたとあなたのマップのリンクに関する情報を含めて、協力して、協力世界に掲載されます。
::: warning 注意
VRChat マップの URL リストは最大 100 個しかありません。必要に応じて追加してください。
:::
:::

## よくあるエラーコード

| HTTP ステータスコード | ビジネスコード | 説明 |
| --- | --- | --- |
| `403` | 固定ビジネスコードなし | サポートされていないプラットフォームリンクのリダイレクトが拒否されました |
| `405` | `METHOD_NOT_ALLOWED` | 缺少 `url` パラメータキー |
| `418` | `IM_A_TEAPOT` | `url` パラメータが空文字列です |
| `422` | `INVALID_URL` | 入力から有効な URL を抽出できませんでした |
| `422` | `MISSING_PARAMETER` | 必要なパラメータがありません |
| `422` | `UNSUPPORTED_PLATFORM` | 現在のプラットフォームまたは現在のリンクタイプはサポートされていません |
| `451` | `CONTENT_RESTRICTED` | 著作権またはコンプライアンス上の理由によりサポートされていません |
| `500` | `PARSE_ERROR` | 一般的な解析失敗 |
| `500` | `COLLECTION_PARSE_ERROR` | コレクション解析失敗 |
| `500` | `PLAYLIST_ERROR` | プレイリスト詳細の取得失敗 |
| `503` | `NO_NODES_AVAILABLE` | 現在利用可能な解析ノードがありません |
| `504` | `PARSE_ERROR` | 上流解析ノードがタイムアウトまたは接続拒否 |
| `429` | `API_LIMIT_EXCEEDED` | API リクエストが頻繁すぎます |
