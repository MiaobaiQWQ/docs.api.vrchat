## 2026年

### 2026/07/10
- 弾幕のないビデオはつまらないと感じていましたか？
- 現在、カフェで最新の V3 インターフェースを使用できます。カフェで弾幕を見ることができるようになりました！ (独自の解析ではなく、内蔵の解析を使用してください。そうしないと弾幕が表示されません)
- V3 インターフェースの主な機能は、弾幕システム (もちろん、Bilibili と Douyin もサポートしています) と、後続の拡張機能である分P再生および音楽再生機能などです。
- YouTube のビデオ解析は、うーん、もう対応できません。とりあえず置いておきます。海外のユーザーは一時的に利用できません。本当に申し訳ありません！

### 26/07/04
- 問題が修正されました：以前は Kuaishou のビデオ解析で断片ファイルしか返されませんでしたが、この問題を修正しました！
- 解析ロジックが最適化され、完全な高品質のビデオリンクが優先され、断片ファイルが除外されます。

### 26/06/23
- IP ブロックメカニズムを追加
- ブロックコンテンツ表示ページを追加
- 非ビデオプラットフォームおよびホワイトリストアドレスの 302 リダイレクトをキャンセル
- 【ブロック理由】サービスはデフォルトでホワイトリスト検証がなく、本日調査した結果、違法なビデオが再生されていることが判明しました。

### 26/06/21
- 一部のバックエンド解析の異常なクラッシュにより、一部のビデオ解析が正常に機能しない問題を修正しました。現在修正済みです。
- 陌白QWQ がドキュメント責任者に調整され、ドキュメントエリアの管理とコンテンツのメンテナンスを担当します。
- 海落QWQ がバックエンドビデオ解析修正に調整され、解析サービスのメンテナンスと障害修正を担当します。
- kole-knol の役職がドメイン提供者サーバー保持者に更新されました。

### 26/06/15
- リンク置換キャッシュ機能を削除しました。同じリンクでも他の人が再生できないのに自分は正常に再生できる可能性があるためです。
- ステータス修復が完了し、サーバーへの影響は小さく、運用が開始されました。

### 26/06/14
- 正しい bv および Douyin リンクが渡されれば正常に解析されるように修正および最適化しました。
- https と www、および対応するプラットフォームのドメインが欠落している場合に正常に解析できない問題を最適化しました。
- 誤ったリンクが渡された場合、ヒント付きの画像が返されるので、それに従って操作してください。
- YouTube のビデオ解析は一時的に修正できません。

### 26/06/13
- youtu.be の一部の短い直リンクアクセスエラーによる解析失敗を修正しました。
- Bilibili ライブの置換ロジックを書き直しました (正常に再生できない場合はお問い合わせください)。

### 26/06/12
- 管理者がサーバーの更新を忘れたため、国内のライブ解析が機能しなくなった問題を修正し、懲罰を行いました。

### 26/06/11
- Bilibili 公式イベントライブが解析できない問題を修正しました。
- 夜更かししてファイルを間違ったサーバーにアップロードしたために解析全体が壊れた問題を修正しました (UTC+8 07:00 に修正済み)。
- Bilibili の短いライブリンク解析失敗を修正しました。
- ライブリンクが誤ってビデオリンクに置換された問題を修正しました。

### 26/06/10
- 一部の Bilibili の古いビデオが正常に解析できない問題を修正しました。
- 応答速度が遅すぎる問題を修正しました。
- 既知のバグを修正しました。

### 26/06/08
- 直リンクの 302 リダイレクトを更新しました。
- 一部のビデオがセキュリティシステムによってブロックされ、「このリンクには安全でないターゲットアドレスが含まれており、システムによってブロックされています」と返される問題を修正しました。
- ビデオ再生が正常に解析されず、「404」と返される問題を修正しました。
- 日本語部分のフィルタリングが不正確で解析が失敗する問題を最適化しました。
- 解析ロジックを最適化し、解析を高速化しました。

### 26/05/26
- Douyin ライブ解析が失敗して再生できない確率が高い問題を修正しました。
- より良いビデオ体験を得るために、非公開の部屋での使用をお勧めします。
- カフェでのビデオ再生が一部機能しない場合があります。
- ⚠️ **重要**: テキスト、特に # が含まれるテキストを必ず削除してください。# の後の内容はサーバーに送信されません。これは RFC 3986 に従っているため、# の後のテキストはサーバーに送信できません。ご了承ください。
