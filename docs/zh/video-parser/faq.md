# 常见问题

本文档列出使用 api.Kipfel.link 视频解析服务时的常见问题解答。

## 支持内容

::: info 已支持的平台
- **视频平台**：抖音、Bilibili、YouTube、Twitter(X)、Instagram、快手、AcFun
- **直播支持**：Bilibili 直播、抖音直播、快手直播 (支持短链自动识别)
- **音乐平台**：网易云音乐、酷狗音乐、咪咕音乐、YouTube Music
- **解析类型**：单视频、合集(B站多P/YouTube列表)、音乐单曲、音乐歌单
:::

## 直播解析说明

::: tip 直播解析功能
- **多平台覆盖**：支持 Bilibili、抖音、快手三大主流直播平台。
- **短链接兼容**：支持手机端分享的短链接（如 `b23.tv`、`v.douyin.com`），系统会自动执行重定向并解析。
- **自动识别**：无需选择类型，直接粘贴直播间地址（去掉文案！ 去掉文案！ 去掉文案！重要事情说三遍！），系统会自动切换到直播解析引擎。
:::

::: warning 注意
直播链接通常带有较强的时效性和防盗链限制，建议解析后尽快使用。
:::

## 基础问题

::: details 为什么网页可以正常播放，但 VRChat 无法正常播放？
VRChat 内置播放器/某些播放器对 302 跳转或长链接支持不完整。先把你复制的链接格在浏览器里打开解析一次，让它跳转到最终地址（通常会变成 `直链`），再把跳转后的链接复制到 VRChat 里播放。
:::

::: details 为什么有的房间无法播放？
VRChat官方于2024.12.11更新后，官方强制所有地图自行配备[域名白名单](https://docs.vrczh.org/creators.vrchat.com/worlds/udon/video-players/www-whitelist)。它的作用是限制在公开房中，只有作者配置的此地图的白名单中的资源链接，才可以被允许访问，私人类型房间则不受限制。
:::

::: details 为什么抖音无法正常解析？
不要直接粘贴带文案的分享内容，尤其是携带#符号，建议删除所有文字，只保留链接本体再重试。
:::

::: details 歌单怎么选第 N 首？为什么播放的不是我想要的那首？
歌单从 1 开始计数。用 `&i=1` / `&i=2` 选择第 N 首；也支持在末尾加 `@1` / `@2`。如果超出范围会提示"歌单序号超出范围"。
:::

::: details 有些视频能解析，但在 VRChat 里卡顿/加载慢？
可能是源站网络波动；也可能是源站限制了国内/海外访问。由于本站已停止视频流量中转服务，建议使用合适的网络环境直接访问源站资源。
:::

::: details 我是某个公开地图的作者？我想添加这个解析站的支持？
请查看 [CDN 列表](/zh/cdn) 页面，获取需要添加到白名单中的完整域名列表。发送 [邮件](mailto:admin@kipfel.link?subject=域名解析列表申请&body=您好，我是xxx地图的作者xxx，需要添加对本站点的解析支持，这是我的地图的邀请链接：) 给作者，并附上你地图链接的信息，进行合作，会放到合作世界里面。

::: warning 注意
VRChat地图限制URLlist最大只有100个，请按需选添。
:::
:::

## 常见错误码

| HTTP 状态码 | 业务码 | 说明 |
| --- | --- | --- |
| `403` | 无固定业务码 | 非受支持平台链接被拒绝重定向 |
| `405` | `METHOD_NOT_ALLOWED` | 缺少 `url` 参数键名 |
| `418` | `IM_A_TEAPOT` | `url` 参数为空字符串 |
| `422` | `INVALID_URL` | 未能从输入中提取出合法 URL |
| `422` | `MISSING_PARAMETER` | 缺失必要参数 |
| `422` | `UNSUPPORTED_PLATFORM` | 当前平台或当前链接类型不支持 |
| `451` | `CONTENT_RESTRICTED` | 因版权或合规原因不支持 |
| `500` | `PARSE_ERROR` | 通用解析失败 |
| `500` | `COLLECTION_PARSE_ERROR` | 合集解析失败 |
| `500` | `PLAYLIST_ERROR` | 歌单详情获取失败 |
| `503` | `NO_NODES_AVAILABLE` | 当前没有可用解析节点 |
| `504` | `PARSE_ERROR` | 上游解析节点超时或拒绝连接 |
| `429` | `API_LIMIT_EXCEEDED` | API 请求过于频繁 |
